# App Store アクセシビリティ対応メモ

## 現在申告できる項目

- ダークインターフェイス
- 視差効果を減らす

## 今後対応・検証する項目

- VoiceOver
  - 主要なボタン、リンク、入力欄、画像に適切なラベルを付ける
  - オンボーディング、ログイン、投稿、地図、プロフィール、設定を一通り操作できることを確認する
- 音声コントロール
  - 表示名またはアクセシビリティ名で主要操作を実行できることを確認する
- さらに大きな文字
  - iOSの文字サイズ設定を反映する
  - 最大サイズでも文字切れ、重なり、操作不能がないことを確認する
- カラー以外で区別
  - ステータスや選択状態を色だけでなく、文字、アイコン、形でも区別する
- 十分なコントラスト
  - ダーク・ライト両テーマでWCAGのコントラストを測定する
- 視差効果を減らす
  - 現在のスケルトンアニメーション停止に加え、全アニメーションを確認する
- キャプション／バリアフリー音声ガイド
  - 将来、音声や動画コンテンツを提供する場合に対応する

## App Store Connect更新前の確認

- 実機のiPhoneで一般的なタスクを最初から最後まで完了できるか確認する
- 対応を確認できた項目だけApp Store Connectで追加申告する
- 日本語と英語の画面・ラベルを両方確認する

## 再開用プロンプト

```text
SpotcodeのApp Storeアクセシビリティ申告を更新したいです。
docs/app-store-accessibility-todo.mdを読み、現在の実装を監査してください。
VoiceOver、音声コントロール、さらに大きな文字、カラー以外で区別、十分なコントラスト、視差効果を減らす、キャプション、バリアフリー音声ガイドについて、未対応箇所を特定してください。
必要な修正を実装・検証し、App Store Connectで新たに申告できる項目と、まだ申告すべきでない項目を根拠付きでまとめてください。
```
