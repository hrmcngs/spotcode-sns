# 今すぐ「App Reviewに返信」へ送れる回答

審査ありがとうございます。ビジネスモデルについて回答いたします。

1. Spotcodeは、開発者やコミュニティの参加者が投稿、GitHubの情報、スポットを共有する無料のSNSです。有料コンテンツ、サブスクリプション、有料機能、有料サービスは提供していません。
2. アプリ内にも外部のWebサイトにも、Spotcodeの有料コンテンツや機能を購入する場所はありません。
3. 過去の購入によってアクセスできるコンテンツや機能はありません。GitHub連携はユーザーが許可したGitHub情報を表示する機能であり、Spotcodeでの購入による機能解放ではありません。
4. アプリ内課金以外の方法で解放される有料機能もありません。登録およびすべての機能が無料です。
5. ユーザーはSpotcodeのWebサイトのSign up画面から、メールアドレス、パスワード、プロフィール情報を入力して無料でアカウントを作成し、iOSアプリへログインできます。アカウント作成に料金はかかりません。

デザイン、規約同意・ブロック機能、サポートURLについても修正を進めています。更新ビルドと実機で撮影した画面録画を準備して、改めて提出いたします。

# 公開・実機確認・動画添付を終えた後に送る追記案

以下は実際に対応が完了してから送信してください。現時点で「動画を添付しました」とは送らないでください。

ご指摘の問題を修正した更新ビルドを提出しました。

- 権限確認の説明を日本語・英語でローカライズし、アプリの言語と一致するようにしました。言語はiOSのアプリ言語設定に従います。
- ログイン前に規約を表示し、同意しなければログインできないようにしました。Webの登録・ログイン前にも同意が必要です。規約は不適切なコンテンツや虐待的な行動を容認しないこと、削除・利用停止を行うことを明記しています。
- 投稿の「…」メニューに通報・ブロック機能を用意しています。ブロックした相手の投稿は直ちにフィードから非表示になり、運営の通知一覧へ対象情報が送られます。運営はその一覧から通報・ブロックを確認します。
- サポートURLを https://hrmcngs.github.io/spotcode-sns/support.html に変更しました。問い合わせ先は spotcode@littleapps.jp です。

規約同意、通報、ブロックによる即時非表示を示す実機の画面録画を添付し、App Review情報のメモ欄にも記載しました。ご確認をお願いいたします。
